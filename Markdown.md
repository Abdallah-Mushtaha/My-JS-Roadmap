## What is Markdown?

Markdown is a lightweight markup language used to write documents in a simple and easy-to-read way. It uses simple text symbols to format text without the need for complex code like HTML.

---

## **Why Use Markdown?**

✅ **Ease of Writing** – Anyone can use it without programming experience.  
✅ **Convertibility** – It can easily be converted to HTML, PDF, or any other format.  
✅ **Widely Used by Developers** – It is widely used in GitHub and README files.  
✅ **Lightweight and Fast** – It doesn't contain unnecessary code that affects performance.

---

## **How to Create a Markdown File?**

1. Open any text editor (**VS Code, Notepad++, or even Notepad**).
2. Create a new file.
3. Save it with a `.md` extension, like **`document.md`**.
4. Start writing the content using simple Markdown syntax.

---

## **Examples of Markdown Formatting**

| Format            | Code Used                                 | Result                           |
| ----------------- | ----------------------------------------- | -------------------------------- |
| **Main Header**   | `# Header`                                | **Main Header**                  |
| **Sub Header**    | `## Header`                               | **Sub Header**                   |
| **Bold Text**     | `**Text**`                                | **Text**                         |
| **Italic Text**   | `*Text*`                                  | _Text_                           |
| **Bullet List**   | `- Item`                                  | - Item                           |
| **Numbered List** | `1. Item`                                 | 1. Item                          |
| **Link**          | `[Link Name](https://example.com)`        | [Link Name](https://example.com) |
| **Image**         | `![Image Description](path/to/image.png)` | Image                            |

---

## **Where is Markdown Used?**

📌 In **GitHub** to write README files and project documentation.  
📌 In **blogs and technical articles** to easily write formatted content.  
📌 In **personal note-taking** in an organized manner.  
📌 In **writing apps like Notion and Obsidian** for creating quick documents.
